# Zombie Defense 100

Godot 4.7.2 Compatibility 기반의 쿼터뷰 게임입니다. 캐릭터·좀비·아이템·공격 그림은 투명 PNG를 사용하는 2D 스프라이트이며, 이동과 충돌은 3D 공간에서 처리합니다.

플레이: https://sanypower90-ops.github.io/zombie-defense-web/

## 진행 규칙

- 총 100라운드. 일반 라운드는 30초 생존하면 다음 라운드로 넘어갑니다.
- 10라운드마다 보스만 출현합니다. 일반 좀비와 소환 좀비는 나오지 않습니다.
- 보스는 시간 제한 없이 처치해야 다음 라운드로 넘어갑니다. 100라운드 최종 보스 처치 시 승리합니다.
- 보스는 360도 방사 탄막으로 시작합니다. 최대 체력의 15%가 닳을 때마다 패턴을 하나 추가합니다. 체력 85/70/55/40/25/10%에서 해금되며, 총 7종 중 해금한 패턴을 무작위로 사용합니다.
- 추가 패턴: 이중 탄막, 회전 나선, 조준 부채, 가속 꽃잎, 역회전 탄막, 삼색 노바. 발사 전 경고 표시와 소리가 나옵니다.
- 적 탄환은 장애물에 막힙니다. 빠른 탄환도 한 프레임 이동 경로로 피격을 검사합니다.
- 실제로 체력이 감소하면 전용 피격음이 나고 캐릭터가 2초 동안 흐릿하게 깜박입니다. 이 시간은 무적이며, 일시정지 중에는 줄어들지 않습니다.

## 무기와 능력

- 기본 무기: 권총, 장검, 주먹. 특수무기는 두 슬롯에 보관합니다.
- 조이스틱 위 버튼에 현재 보관한 무기 이름과 남은 발수를 표시합니다.
- 자동 공격 능력: 드론, 전기, 화염, 회전 칼날, 미사일. 선택한 그림은 플레이어 주변을 따라다니며, 그 위치에서 구별되는 투사체가 적에게 날아갑니다.
- 새로운 능력·탄막 그림: `assets/sprites/combat_v4.png`. 기존 공격·명중 이미지도 함께 사용합니다.
- 무기 12종과 좀비 사망·플레이어 피격·보스 경고·발사 소리를 별도로 합성했습니다. 원본 생성기는 `tools/generate_sfx.py`, WAV 파일은 `assets/audio/sfx/`에 있습니다. 외부 오디오 샘플을 사용하지 않았습니다.

## 조작

- PC: WASD/방향키 이동, 마우스 조준, 좌클릭 공격. 1/2/3 무기 슬롯, 4 장검, 5 주먹, R 권총 재장전.
- 모바일: 중앙 하단 조이스틱으로 이동과 사격 방향을 함께 조작합니다. 제자리에서 누르고 있어도 공격합니다.
- 오른쪽 위 메뉴에서 홈·일시정지/계속하기·다시하기를 사용할 수 있습니다.

## 계정과 저장

- Supabase 공용 서버에서 동일한 Top 10을 읽습니다. 연결 오류 시 기기별 랭킹으로 바꾸지 않습니다.
- 아이디·비밀번호 가입/로그인은 Supabase 계정 함수로 처리합니다. 로그인한 계정의 보관 아이템·무기는 본인 계정 저장소에 저장하고 불러옵니다.
- 비로그인 보관함은 같은 브라우저의 로컬 저장소를 사용합니다. 브라우저 데이터 삭제 시 사라질 수 있습니다.
- 시작하기는 1라운드부터 시작합니다. 체크포인트 라운드 이어하기는 없습니다.
- 클라이언트 점수 제출 방식이므로 서버에서 플레이 전체를 검증하는 치트 방지 구조는 아닙니다.

## 실행·검증·배포

`godot --headless --path game --import` 후 `tests/`의 smoke, sprite_visuals, ability_effects, ability_combat, boss_hit, orbit_range 테스트를 실행합니다.

`.github/workflows/pages.yml`은 이 여섯 검사를 통과한 뒤 Web export와 GitHub Pages 배포를 진행합니다. 싱글스레드 Web export를 사용합니다.

홈 화면에 추가해서 실행하면 PWA standalone 화면으로 사용할 수 있습니다. 일반 브라우저 주소창은 게임에서 강제로 숨기지 않습니다.

## 사거리·회전 수호 능력·이미지 수정 (v5)

- 자동 공격 5종의 탐색 사거리를 기존의 정확히 2배로 늘렸습니다. 새 `flight_v5.png` 투사체·명중 그림과 최대 6개의 짧은 잔상을 사용합니다.
- 기본무기 버튼을 클릭하면 권총·장검·주먹 목록이 열리고, 선택하면 바로 장착됩니다. 목록이 열려 있는 동안 게임은 일시정지합니다. PC에서도 하단 무기 버튼을 표시합니다.
- 게임 메뉴에 홈으로 바로가기와 다시하기를 추가했습니다. 홈 이동 전에 보관 아이템을 저장합니다.
- 수호 구체·수호 칼날 강화는 각각 최대 5레벨이며, 레벨마다 개체가 1개 추가됩니다. 반경 3의 원형 궤도를 돌며 5초 활성·2초 비활성 주기를 반복합니다.
- 활성 개체에 닿은 좀비는 피해를 받으며 그대로 통과합니다. 개체는 물리적인 벽이 아닙니다. 적 미사일이 개체에 닿으면 차단하고, 활성 중 플레이어가 받는 피해를 25% 줄입니다. 비활성 시간에는 공격·방어 효과가 모두 꺼집니다. 일시정지하면 주기도 멈춥니다.
- `zombies_v5.png`, `heavy_v5.png`, `props_v5.png`로 일반/특수 좀비·보스·지형 6종을 교체했습니다. 생성 시트의 불규칙한 기존 좌표 대신 동일한 4×4 격자를 사용합니다. 미세한 알파 잡음을 제외하고 전신을 비율대로 축소해 머리·손·발이 고정 캔버스에 잘리는 일을 막습니다.

## v6 — 능력 역할과 근접 무기
- 회전 칼날(`auto_blade`)도 수호 개체처럼 플레이어 중심 궤도를 따라 이동합니다. 5초 작동/2초 휴식, 레벨당 +1개입니다.
- 보스를 제외한 모든 좀비의 그림과 충돌 크기 20% 감소.
- 궤도 드론: 3초마다 주변 무작위 적을 향해 3~7발의 스플래시 미사일 난사. 적이 하나여도 여러 발 발사.
- 전기 충격: 3.2초마다 주변 바닥에 트랩 설치. 6초 유지, 0.8초마다 범위 피해와 0.5초 감전. 위치 고정, 일시정지 중 시간 정지.
- 추적 화염탄: 1.4초마다 추적 단일 적 공격, 기존 자동 기본 피해의 2.8배.
- 추적 미사일: 2초마다 추적 발사, 직접 피해와 폭발 범위 피해.
- 장검: 피해18, 초당2회, 거리5.5, 넓은 부채꼴 베기와 일러스트 베기 효과.
- 주먹: 피해22, 초당7회, 거리1.8, 좁은 정면 범위. 양손 번갈아 공격.
- 새 전신 장검/주먹 모션 아틀라스: `player_melee_v6.png`, `player_melee_back_v6.png`. 권총 그림 대신 무기별 준비/공격 동작을 표시합니다.
- 검증: 기존6개 + `ability_roles_test.gd` (7개).
