# Game sprite sheets

These PNG sheets were supplied by the game creator. Runtime crops the original sheets with AtlasTexture. `player_actions.png` animates the player, `zombie_groups.png`, `armored_exploder.png`, and `boss_groups.png` animate enemies, `items_props.png` supplies items and street objects, and `projectile_fx.png` and `weapon_fx.png` supply combat effects.
