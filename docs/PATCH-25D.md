## 적용

- 고정된 비스듬한 직교 카메라. 이동·조준·캐릭터 방향은 카메라 방향에 맞게 변환.
- 새 폐허 바닥, 일반 좀비 16개 포즈, 낡은 차량·방호벽·가판대·불타는 드럼통 등.
- 새 이미지의 개체 외곽을 직접 측정한 JSON으로 분리. 기존 원본 유지.
- 바닥 그림자는 MultiMesh 한 번의 묶음 그리기로 표시. 불빛은 네 개의 작고 단순한 면 효과.
- 자동공격 ON/OFF 버튼은 조이스틱 오른쪽. 작은 반투명 설명 두 줄.
- ON: 사거리·장애물·생존 여부를 확인해 목표를 유지하고 자동 사격. 정상 탄약 소모.
- OFF: 기존 조이스틱/마우스 방향 공격. 자동 공격 능력의 기존 동작은 유지.
- UI 버튼 터치는 이동 조이스틱으로 전달되지 않음.
- 개인 계정, 아이템 DB, 랭킹 서버 데이터와 기능은 변경하지 않음.
